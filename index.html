§ 02 Method

From how a crop grows to what a grower decides.

My work follows one chain: understand the crop, measure the field, test the model, then put it where decisions get made.

01 Crop physiology

Start with how the crop actually grows.

My doctoral research examined soil-water balance, crop growth, root distribution, water uptake and yield under deficit irrigation in corn and soybean. Phenology, water stress, nutrient and residue processes — that physiology is what a process-based model has to get right first.

  • Corn & soybean phenology
  • Soil-water balance
  • Root-zone water uptake
  • Deficit irrigation

§ 03 Case files

Selected work, in detail.

Six projects across crop-model implementation, doctoral research, a commercial platform and client work. Start with the DSSAT strawberry project, then open any case file for the methods and tools.

01 Applied crop-model project · DSSAT/CROPGRO-Strawberry

DSSAT,
in Python.

Crop processes, made inspectable in code.

I developed a Python implementation adapted from DSSAT/CROPGRO-Strawberry to simulate strawberry growth. It connects thermal-time phenology, canopy photosynthesis and biomass allocation with fruit development.

The project includes utilities to read DSSAT experiment and weather inputs, run the Python model and compare its outputs with the Fortran model. That workflow supports inspection of the implementation and its differences from the original model.

  • Phenology
  • Photosynthesis
  • Biomass allocation
  • Fruit development

02 Doctoral research → web application · 2013–2016

CornSoyWater

A model is only useful when it helps a grower decide.

During my Ph.D. at the University of Nebraska–Lincoln, I developed CornSoyWater, a web application for corn and soybean irrigation decisions that connects process-based crop simulation with weather, soil and field-management inputs.

I evaluated model performance using five years of field data and a two-year irrigation experiment, examining soil-water balance, crop growth, root distribution, water uptake and yield under deficit irrigation.

03 Lindsay Corporation · Aug 2018 – Jul 2021

Crop science at commercial scale.

Thirty crop models, satellite-informed phenology and R&D field trials. Modeling & product

As FieldNET Advisor Solutions Specialist (Data Scientist), I developed and maintained 30 crop models — including corn, soybean and cotton — for Lindsay’s commercial FieldNET Advisor irrigation platform. I prototyped in Python and used R cross-validation to evaluate performance.

I modified and improved FieldNET Advisor software, including API integration with John Deere Operations Center.

I led R&D field trials measuring soil moisture, phenology and yield, supervised interns, and translated model findings into reports for product and agronomy teams. I also co-invented a patented irrigation-scheduling method.

04 CIBO Technologies · Aug 2021 – Present

Understand what the model is telling you.

SALUS sensitivity analysis and quality-checked field-level data. Model evaluation

As Quantitative Agricultural Scientist, I evaluated SALUS sensitivity to tillage depth and management, soil temperature and moisture, and planting and harvest dates to explain crop maturity and simulated soil responses.

I integrated manure parameters into SALUS, explored nitrogen-related outputs and tested residue parameters, then compared simulated and measured residue-related outputs to assess model behavior and identify limitations.

Alongside the modeling, I built Python and Scala workflows on AWS to clean, quality-check and tabulate field-level farm-management data for Verra carbon-credit verification, prepared field polygons and agricultural reports, and created scripts to ingest trial soil-moisture, temperature and CO₂ observations. Analyses were documented in Confluence, with code reviewed through GitHub pull requests.

Methods & tools

  • SALUS
  • Sensitivity analysis
  • Simulated vs. measured residue outputs
  • Python · Scala · AWS
  • Verra verification data

05 Consulting client projects · Feb 2017 – Aug 2018

Better predictions, clearer decisions.

Crop-stage prediction, multi-location trials and geospatial reporting. Agronomic analytics

As a Data Scientist and Software Engineer with Novedea / Colaberry / QCI consulting, I worked on client projects for Climate Corporation, DuPont Pioneer and Monsanto. For Climate Corporation, I improved crop growth-stage prediction error from approximately ±7 days to ±3 days for a model deployed in a product, and analyzed soybean phenology and its environmental drivers.

I evaluated genotype-by-environment effects in multi-location trials using mixed models and variance components, with automated feature selection and quality checks, and used gradient boosting, random forests and logistic regression to investigate agronomic drivers.

I processed gigabyte-scale field, hybrid-trial and climate datasets from agricultural APIs and data warehouses using Spark, Python and R on AWS EC2, developed NDVI composites and true-color imagery for Pioneer projects, mapped results in QGIS, Tableau and Spotfire, and delivered weekly slide briefings to leadership.

Methods & tools

  • Mixed models
  • Variance components
  • G×E analysis
  • NDVI composites
  • QGIS · Tableau · Spotfire
  • Spark · Python · R
